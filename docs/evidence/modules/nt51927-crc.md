# NT51927 CRC-only module gate

The supported unchanged interface is:

```text
NT51927BASED_GEN_CRC_MODE <CRC8|CRC32> <input-bin> <output-bin>
```

`tests/module/test_nt51927_crc.py` builds a single linked flash-header fixture
for IC_M. It validates, against the pinned EXE and for both CRC methods, the
common header CRC, ILM/DLM copies into RAM, their CRC fields, and the flash
header CRC. The test requires equal process result, console streams, and every
output byte.

Not yet covered: multiple linked headers, IC_L / IC_R routing, malformed
sector ranges, and the legacy 16 MiB RAM boundary cases.
