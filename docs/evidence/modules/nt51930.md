# NT51930 normal-mode gate

The following unchanged interface has a no-overlay differential gate:

```text
NT51930BASED_NORMAL_MODE <CRC8|CRC32> <output-bin> <firmware-bin> \
  <block-bin> <source-hex> <destination-hex> <length-dec> [...]
```

`tests/module/test_nt51930.py` verifies reference EXE and Python exit code,
stdout and all 262,144 output bytes.  Its fixture exercises IC count 2,
4096-byte FwConfig relocation, the trailing `\0NVT` flag, ILM/DLM CRCs, one
DLM-diff CRC and the common 0x24-byte header CRC.

| CRC method | Reference output SHA-256 |
| --- | --- |
| CRC8 | `89d0e3748c16aba2ebf50dfc8142c7b041c0727152a0afdbcc18f82b8c15836e` |
| CRC32 | `04b4e1b632624b02454fc198604aad6ac8fd2aa67cd25de12a8a08446094b074` |

`tests/module/test_nt51930_overlay.py` adds the ordinary one-descriptor
`_ovly_table =` path for both CRC methods:

| CRC method | Reference overlay output SHA-256 |
| --- | --- |
| CRC8 | `b19e98d466cfa08e24177d8ea4cbf1a051c2fa06a69008c51b72bf2af048348f` |
| CRC32 | `d42a3c93cf2d3f8b5bc97e959993e33d42a079c12d33d12d1ec3e8fad444de4c` |

Excluded: HostDL/Process `OverlayDLMaddr` mutation, 512 KiB / high-IC test
data, and malformed pointer/source-range cases that are undefined in the C
program.
