# NT36672A merge-and-CRC gate

The unchanged interface is covered:

```text
NT36672ABASED_MERGE_BIN_AND_GEN_CRC_MODE <CRC8|CRC32> <output-bin> \
  <firmware-bin> <block-bin> <source-hex> <destination-hex> <length-dec> [...]
```

`tests/module/test_nt36672.py` runs pinned Combiner 1.13 and the Python
implementation with identical argv, then compares exit code, stdout, and all
output bytes.  It covers CRC8 / CRC32 on one common header plus the
two-header cascade branch.  Reference output SHA-256 values:

| Case | SHA-256 |
| --- | --- |
| CRC8, one header | `1b5eb5a16b38517589e4e842f7ad909bca5b7ff0d2293d24e8fdc9bc5d4aa1b1` |
| CRC32, one header | `a57fe0894f58fc7f955165f5b256a158b6a6b1da6d899678aa96497ab2059555` |
| CRC8, cascade headers | `301c1b481ecd26b9280a8030bf7b35460d12f84c17dc165042b188c320b2ef96` |

Excluded: undefined C behavior from invalid pointers or source ranges, and
uninitialised allocation gaps that are not present in the synthetic fixture.
