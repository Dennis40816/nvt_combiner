# NT51928B normal-mode gate

The unchanged no-overlay interface is verified:

```text
NT51928BBASED_NORMAL_MODE <CRC8|CRC32> <output-bin> <firmware-bin> \
  <block-bin> <source-hex> <destination-hex> <length-dec> [...]
```

`tests/module/test_nt51928b.py` compares pinned Combiner 1.13 against Python
for process exit code, stdout and every output byte.  The fixture covers the
1920-byte FwConfig copy to `0x3E000`, ILM/DLM data CRCs and the 0x30-byte
`0xD100` header CRC.

| CRC method | Reference output SHA-256 |
| --- | --- |
| CRC8 | `ff54bd5a9fdefefb5425acd4aa67c522cf4e62c850114a5f205f49aa810f4db4` |
| CRC32 | `a5740559d7f977c47e144a84f88dd8554a915f7b1ab568286f3f104a93186f29` |

`tests/module/test_nt51928b_overlay.py` adds one ordinary `_ovly_table =`
descriptor for both CRC methods:

| CRC method | Reference overlay output SHA-256 |
| --- | --- |
| CRC8 | `97426501d8d18b12155a1dd2639cd53dfd8891ac4cbc68aa7cb773a4106c69c2` |
| CRC32 | `0acda46d42c8173118a24fbb8d3784df236edcce840e531773e3d3df02877f19` |

Excluded: HostDL/Process `OverlayDLMaddr` mutation and invalid pointer/source-
range calls that depend on undefined C memory behavior.
